Load it in Python

import json

rows = [json.loads(line) for line in open("ghatna_chakra_all_india.jsonl", encoding="utf-8")]
print(len(rows), "questions")

# supervised prompt / answer pair
def as_pair(q):
    options = "\n".join(f"{k}. {v}" for k, v in q["options"].items())
    return f"{q['question']}\n{options}\nAnswer:", ", ".join(q["answer_text"])

# only BPSC-asked questions from 2015 onwards
bp = [q for q in rows if "B.P.S.C." in q["exam"] and (q["year"] or 0) >= 2015]

Nothing is dropped from the full exports — every question in the source appears in ghatna_chakra_all_india.jsonl and its subject file. Text repairs (split ligatures such as “fi rst”, wrapped lines, exam labels inside options) are applied mechanically; anything that could not be repaired safely is flagged instead of guessed.
