# Chapter-wise Polity PYQ sheet

Open `Polity_PYQ_Laxmikanth_Chapterwise.pdf` for the printable version, or `Polity_PYQ_Laxmikanth_Chapterwise.xlsx` to filter the single worksheet by chapter. It contains 515 rows: all 324 numbered questions in the supplied KGS polity PDF, JSON records labelled `polity`, and CSV records labelled `Polity`. Eighty-six records with the same normalized question **and complete options** were merged, retaining source references. Differently worded versions and questions with different options remain separate, even where they may refer to the same exam question.

The chapter assignment is a best-fit, automated index based on the supplied Laxmikanth text and the PDF's topic sequence; it is not a verified chapter-by-chapter expert classification. Later chapter numbers are omitted because the supplied text's index is incomplete. **93 rows are in “Review / outside Laxmikanth chapter scope”**: the source material includes some international affairs, current affairs and other off-topic questions. Check these before using them as a polity-only list. Other assignments also need review, particularly questions spanning chapters.

Answers are copied from the sources, not independently verified. The PDF has extraction/OCR defects, including incomplete option tables and occasional translation or key errors. A `*` or multi-letter PDF key is retained as printed; check the PDF rather than assuming what it means. The JSON may abbreviate some 71st-exam questions; compare those with the CSV. Some records may remain duplicates because of differing wording, punctuation beyond normalization, or changed options. Historical answers and facts may no longer be current. Check source references and original papers before relying on a question or answer.

To rebuild, install `pypdf` and `openpyxl`, then run `python scripts/compile_polity_pyq.py INPUT_DIRECTORY OUTPUT.xlsx`, where the input directory contains the supplied PDF, JSON and CSV. The book text is used as the chapter reference, not reproduced in the sheet.
