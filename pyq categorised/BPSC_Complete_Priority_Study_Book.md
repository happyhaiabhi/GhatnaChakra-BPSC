### Ranking logic
1. **Bihar Special (P1)** — unique to BPSC; decides rank vs generic UPSC notes.
2. **Modern History (P2)** — large, static, high repeat.
3. **Polity (P3)** — high weight; PRI + Parliament dominate (see 10-day polity plan).
4. **Geography (P4) & Economics (P5)** — steady mid-weight static.
5. **Ancient + Medieval (P6–P7)** — smaller but easy marks if done together.
6. **Science Bio→Chem→Physics (P8–P10)** — NCERT + Lucent style.
7. **Math (P11)** — not last in *practice*; do **daily** while static runs.
8. **Current Affairs (P12)** — highest count but volatile; **daily habit**, heavy revise last 8–12 weeks.

## 2. How to cover (operating system)

### Daily (every day of preparation)
| Block | Time | What |
|---|---|---|
| CA | 45 min | Newspaper/monthly notes — last 12 months rolling |
| Math | 45–60 min | 15–20 Q practice (arithmetic → TSW → algebra → reasoning) |
| Static | 3–4 hr | One priority subject block (book + NCERT + PYQs in site) |
| Night | 20 min | Wrong-answer flash / Article or date cards |

### For every subject / subtopic
```
1. Read book chapter / NCERT (concepts)
2. Make 1-page notes (facts, lists, articles, years)
3. Open site → that subtopic → Quiz mode (all PYQs)
4. Mark wrongs → weekly Wrong-only filter
5. Move to next subtopic (already sorted by PYQ count)
```

## 5. Compressed plans

### If only 6 weeks
1. Bihar (all)  
2. Modern History  
3. Polity (PRI+Parliament+FR+Federal)  
4. Geography + Economics (selective high subtopics)  
5. Ancient+Medieval one-pass  
6. Science Lucent one-pass + Math daily + CA last 8 months  

### If only 30 days
- **Day 1–8:** Bihar all PYQs + notes  
- **Day 9–14:** Modern + Polity high topics  
- **Day 15–20:** Geo + Eco high topics  
- **Day 21–24:** Ancient+Medieval+Science rapid  
- **Day 25–27:** Math + CA  
- **Day 28–30:** Quiz All + wrongs + Bihar redo  

### Non-negotiables
- Never skip **Bihar Special** and **Modern + Polity** cores.  
- Never skip **daily Math + CA**.  
- Final week = **wrongs + Bihar + mixed Quiz All**, not new books.
