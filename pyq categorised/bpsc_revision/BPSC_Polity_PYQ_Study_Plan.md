### Pattern verdict for BPSC (vs UPSC)

- **Local Government is disproportionately huge** (~21% of Polity PYQs). UPSC aspirants under-weight this; for BPSC it is core.
- **Parliament procedure** (Money Bill, Cut Motion, Vote on Account, absence, office of profit, Speaker powers) beats deep theory.
- **Article numbers** are asked directly (17, 40, 243I/J, 280, 324, 330, 360, 102, 120…).
- **Borrowed features + famous amendments (42nd, 73rd, 91st, 104th)** recur.
- **One-liner factual** style dominates; long philosophical FR essays do not.
- Bihar-only constitutional/governance items were tagged **Bihar Special** (not in this 115) — revise them in Bihar notes separately.

| **NCERT Class 10 – Democratic Politics-II** | Parties / Federalism | Ch.1 Power Sharing, Ch.2 Federalism, Ch.4 Political Parties |
| **NCERT Class 11 – Political Theory** (selective) | Rights vocabulary | Rights/Freedom chapters only if FR is weak |
| **This PYQ list (115 Qs)** | Exam mirror | Topic-wise after each chapter; full set × 3 in final week |
| Bare Constitution (app OK) | Article drill | Only high-frequency Articles from the flashcard list |

**Do NOT** juggle multiple guidebooks. Laxmikanth + NCERT 11 ICW + these PYQs is enough for BPSC Prelims Polity.

### Three-layer loop

```
Layer A  Topic-wise   → same day you finish the chapter (learning mode)
Layer B  Phase-wise   → end of each phase (mixed 20–30 Qs)
Layer C  Full set     → 3 sittings of all 115 in Week 9 (exam mode)
```

### Marking rules

| Result | Action |
|---|---|
| Correct + confident | Tick; rely on fact bank |
| Correct + lucky | Write exact Article / Laxmikanth line in error log |
| Wrong | Error log: Q \| Your answer \| Correct \| Concept gap \| Article/page |
| Law changed (e.g. Anglo-Indian pre-104th) | Note “provision history”; still learn both old & new |

### Spaced repetition

- **Day 0:** learn chapter

- **Day 7:** Article flashcards
- **Day 21:** redo wrongs only
